Install Node.js v24 LTS

  1. Go to nodejs.org.
  2. Click Get Node.js.
  3. At the top of the download page, confirm the version is set to v24.21.0 LTS.
    • Select the version labeled LTS.
    • Do not select v26.8.2, labeled Current.
  4. Select your computer's operating system:
    • Choose macOS if you have a Mac.
    • Choose Windows if you have a Windows computer.
  5. Do not select or follow the Docker instructions.
  6. Scroll down to the section beginning "Or get a prebuilt Node.js…"
  7. Select the appropriate installer:
    • Mac: download the Installer (.pkg).
    • Windows: download the Installer (.msi).
    • If asked for your computer's architecture, use the option it recommends automatically — most recent Macs use ARM64, most Windows laptops use x64.
  8. Open the downloaded installer.
  9. Complete the installation using the default options.
  10. After installation finishes, open a terminal:
    • Mac: open the Terminal application.
    • Windows: open Windows Terminal or Command Prompt.
  11. Type the following command and press Enter:
    node -v
  12. You should see a version number — probably v24.21.0 if you followed the steps above.
If you see a different version starting with v20 or higher (e.g. v22, v25, v26), Node is already installed — no need to reinstall just for this class. If you see something below v20, or "command not found," close and reopen the terminal and try again. If it still doesn't work, tap Summary above for troubleshooting steps.

Claude Code can help: if you already have it installed, try asking: "Help me install Node.js v24.21.0 LTS using the official prebuilt installer. Do not use Docker. Then help me verify the installation using node -v."
Why: Node.js is the software that lets you do more interesting things with your website and the other tools you'll build.

Create a Parley API key

  1. Go to platform.parley.mit.edu.
  2. Sign in using your MIT account.
  3. Click + New key.
  4. When asked who the key is for, select For me (not "Kerberos" or "Moira list").
  5. Under Key label, enter: personal-site
  6. Leave Key expiry at its default setting.
  7. Under API Key Budget Limits, enter:
    • Monthly budget cap: $5
    • Alert threshold: 50%
  8. Double-check the form shows: For me · Key label personal-site · budget cap $5 · alert 50%.
  9. Click Issue key.
  10. Copy the entire API key immediately.
  11. Save it somewhere private and easy to find on Monday — e.g. a private note on your laptop.
Important: treat your API key like a password. Don't email it, put it in a shared document, paste it into your website's code, or upload it to GitHub. We'll set it up securely in class.

The $5 is a spending limit, not a target — MIT gives each student $30/month in Parley credits, and Monday's build will use only a small slice of that.
Why: the Parley API lets the tools you build use AI in the background, even when your laptop is shut down. Your key gives them permission to do that using your account and credits. More on this Monday.

  7. Return to Claude's connector settings and confirm Google Drive shows as connected.
Why: the shared folder will contain new material for your digital MBA advisor.

Create a GitHub account

  1. Go to github.com.
  2. Click Sign up in the top right.
  3. Enter your email, create a password, and choose a username.
    • Tip: pick something simple and professional — this may become a public profile you share later, e.g. in a portfolio.
  4. Verify your email using the confirmation code GitHub sends you.
  5. Answer (or skip) the short personalization questions.
  6. You should land on your GitHub dashboard — that's it for now. We'll create your first repository together in class.
Already have a GitHub account? No need to make a new one — just make sure you remember the username and password.
Why: GitHub is where your code will live online, and where Vercel (next step) pulls from to publish your website.
Want a head start? GitHub's own Get started with GitHub docs and Beginner's guide to GitHub repositories are both short, official, and beginner-friendly — not required, just there if you're curious before class.

Create a Vercel account

  1. Go to vercel.com.
  2. Click Sign Up.
  3. Choose Continue with GitHub, using the same account you just created in Step 6, and authorize Vercel to access it.
    • Signing up with GitHub keeps things simple — Vercel publishes directly from your GitHub repositories.
  4. Complete (or skip) the short onboarding questions.
  5. You should land on your Vercel dashboard with no projects yet — that's expected. We'll create and deploy your first project together in class.
Why: Vercel takes the code you write and puts it live on the internet as a real website, with its own link you can share.
Official reference: Getting started with Vercel.
